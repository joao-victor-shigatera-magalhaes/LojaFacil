# LojaFácil

Sistema de consulta e gerenciamento de preços de produtos, desenvolvido como projeto acadêmico do curso de Análise e Desenvolvimento de Sistemas (ADS).

## Sobre o projeto

O LojaFácil tem como objetivo facilitar o cadastro, a consulta e o gerenciamento de produtos, categorias e usuários.

O projeto está em desenvolvimento e aberto à colaboração dos integrantes da equipe.

## Tecnologias utilizadas

- PHP (programação estruturada)
- MySQL 8.0
- MySQLi
- HTML
- JavaScript

## Estrutura do projeto

- `backend/` — arquivos responsáveis pelas operações e regras do sistema.
- `frontend/` — páginas e interfaces do usuário.
- `database/` — scripts SQL do banco de dados.

## Como obter o projeto

Clone o repositório:

```bash
git clone https://github.com/joao-victor-shigatera-magalhaes/LojaFacil.git
```

Configure o banco de dados utilizando o arquivo `database/estrutura.sql`.

Crie seu próprio arquivo `.env` com as configurações locais do MySQL, utilizando `.env.example` como referência.
